# Etalon role → hex

Source: King/Inspector table from etalon PNG.

| Role | Hex |
|------|-----|
| keyword | `#FF9944` |
| string literal | `#BAE67F` |
| method | `#FFD580` |
| decorator name | `#FFE6B3` (cream, not cyan) |
| ThemeId / TokenDto | `#B9F6CA` |
| class / this | `#5CCFE6` |
| Map / Readonly / Http* / Date / string-ann | `#D5BFFF` |
| param / prop | `#F29E74` |
| punct / fg | `#CBCCC6` |

Methods and strings are **not** `#FF9944`.
